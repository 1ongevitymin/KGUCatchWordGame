### CatchWord (Java)

Java와 Swing으로 만든 오프라인 한글 단어 맞추기 데스크톱 게임입니다. 섞여 있는 글자 버튼을 순서대로 눌러 목표 단어를 완성합니다. 단어 길이와 격자 크기로 난이도(1~5단계)가 나뉘고, 3단계부터는 화면이 어두워지거나 글자가 잠기는 장애물이 나옵니다. 화면의 글자는 모두 한국어입니다.

### 사용 기술

- Java 17, Swing (`java.desktop` 모듈, 별도 라이브러리 없음)
- 저장: 프로젝트 폴더 안의 텍스트 파일 (`data\`)
- 개발 환경: Eclipse (프로젝트 설정 파일 포함)

### 실행 방법

**1. JDK 설치**

JDK 17 이상을 설치합니다. (프로젝트는 JavaSE-17로 설정되어 있고, 21에서 컴파일을 확인했습니다.)

**2. 컴파일**

저장소를 내려받은 폴더에서 실행합니다.
```
dir /s /b src\*.java > sources.txt
javac -encoding UTF-8 -d bin @sources.txt
```

**3. 게임 실행**

```
java -cp bin main.GameManager
```
이미지와 데이터 파일을 상대경로로 읽으므로 반드시 프로젝트 맨 위 폴더에서 실행해야 합니다. Eclipse에서는 프로젝트를 가져온 뒤 `GameManager`를 실행하면 됩니다.
`data\player.txt`, `data\record.txt`가 없으면 처음 실행할 때 빈 파일이 만들어집니다.

### 조작법

시작 화면에서 로그인하거나 회원가입을 하면 메인 메뉴로 넘어갑니다.

| 메뉴 | 동작 |
| --- | --- |
| 사용자 정보 | 내 ID와 최고 점수, 최고 레벨 확인. 로그아웃도 여기서 합니다. |
| 랭킹 | 최고 점수 순위표 |
| 게임 START | 난이도(1~5단계)를 고르고 게임 시작 |
| 게임설명 | 게임 규칙 안내 |
| 게임 종료 | 확인 후 기록을 저장하고 종료 |

게임 화면에서는 다음과 같이 조작합니다.

| 입력 | 동작 |
| --- | --- |
| 글자 버튼 클릭 | 목표 단어의 글자를 순서대로 선택. 맞으면 해당 글자가 파란색으로 바뀝니다. |
| 일시정지 버튼 | 시간을 멈춥니다. 한 판에 한 번만 쓸 수 있고, 다시 누르면 새 단어로 이어집니다. |
| 힌트 버튼 | 지금 눌러야 할 버튼에 빨간 테두리가 깜박입니다. (4, 5단계) |
| 시간 추가 버튼 | 남은 시간을 10초 늘립니다. 60초를 넘길 수 없습니다. (4, 5단계) |
| 연필 아이콘 | 잠긴 버튼(글자 가림)을 모두 풉니다. (3~5단계) |
| 스위치 아이콘 | 어두워진 화면(암전)을 다시 밝힙니다. (3~5단계) |

- 틀린 글자를 누르면 시간이 1초 줄고 화면이 잠깐 빨갛게 깜박이며, 새 목표 단어로 바뀝니다.
- 힌트와 시간 추가는 한 판에 둘 중 하나만 쓸 수 있고, 쓰면 점수가 5점 깎입니다.
- 시간이 0초가 되거나 5문제를 모두 맞추면 게임이 끝납니다.

### 난이도

모든 단계가 5문제이고 제한 시간은 60초입니다.

| 단계 | 단어 길이 | 격자 | 문제당 점수 | 정답 시 추가 시간 | 아이템, 장애물 |
| --- | --- | --- | --- | --- | --- |
| 1 | 3글자 | 3×3 | 1 | 없음 | 일시정지 |
| 2 | 4글자 | 3×3 | 2 | 없음 | 일시정지 |
| 3 | 5글자 | 3×3 | 3 | 3초 | 일시정지, 장애물 |
| 4 | 6글자 | 4×4 | 4 | 4초 | 일시정지, 힌트 또는 시간 추가, 장애물 |
| 5 | 7글자 | 4×4 | 5 | 5초 | 일시정지, 힌트 또는 시간 추가, 장애물 |

- 장애물은 7초마다 암전과 글자 가림 중 하나가 무작위로 나옵니다. 암전은 모든 버튼을 막고 목표 단어를 가리며, 글자 가림은 버튼 3개를 잠급니다.
- 최종 점수는 `맞춘 문제 수 × 문제당 점수 + 남은 시간 × 단계 점수 − 아이템 감점`입니다.
- 최고 기록은 점수가 오르면 점수와 레벨을 함께 갱신하고, 점수가 같으면 레벨이 더 높을 때만 레벨을 갱신합니다.
- 랭킹은 최고 점수가 높은 순이고, 같으면 레벨이 높은 순입니다. 점수와 레벨이 모두 0인 사용자는 표시하지 않습니다.

### 저장 위치

계정과 기록은 `data\` 폴더의 텍스트 파일에 저장됩니다. 서버로 보내지는 데이터는 없습니다.

- `words.txt`: 단어 목록 (한 줄에 하나, 3~7글자 180개)
- `player.txt`: 계정 (`ID 비밀번호`, 한 줄에 한 명)
- `record.txt`: 사용자별 최고 기록 (`ID 최고점수 최고레벨`)

`player.txt`와 `record.txt`는 실행하면서 바뀌는 사용자 데이터라서 `.gitignore`에 들어 있습니다. 형식은 `player.sample.txt`, `record.sample.txt`를 참고하세요. 기록을 초기화하려면 `record.txt`를 삭제하세요. 계정까지 지우려면 `player.txt`도 삭제하면 됩니다.

### 폴더 구조

```
src\main\GameManager.java     실행 진입점, 로그인과 메인 화면 흐름, 파일 읽기와 쓰기
src\main\MainFrame.java       메인 창
src\main\MainMenu.java        메뉴 화면 (사용자 정보, 랭킹, 게임설명, 난이도 선택)
src\main\Player.java          계정 정보
src\main\PlayerRecord.java    최고 점수와 최고 레벨
src\login\                    시작, 로그인, 회원가입 화면 (StartFrame, LoginFrame, JoinFrame)
src\game\Catchword.java       게임 본체 (타이머, 라운드, 아이템, 장애물)
src\game\Difficulty.java      단계별 설정값
src\game\ScorePanel.java      결과 화면
src\game\Button.java          글자 버튼 모양 (벽돌 이미지)
src\module-info.java          모듈 선언
resources\imgs\               화면 배경과 아이콘 이미지
data\                         단어 목록, 계정, 기록 파일과 형식 예시
```

### 알려진 한계

- 비밀번호가 `player.txt`에 암호화 없이 저장되고, 입력할 때도 화면에 그대로 보입니다. 연습용으로만 쓰세요.
- ID와 비밀번호에 공백이나 탭을 넣으면 파일을 읽을 때 깨집니다.
- 글꼴은 `돋움`을 지정했습니다. 설치되어 있지 않은 환경에서는 글자 모양이 달라지거나 크기가 어긋날 수 있습니다.
- 파일 경로가 상대경로라서 프로젝트 폴더가 아닌 곳에서 실행하면 이미지와 단어 목록을 찾지 못합니다.
- 일시정지 중에도 장애물 타이머는 계속 돌고, 일시정지를 풀면 단어가 새로 바뀝니다.
- 로그인, 회원가입 화면을 기다리는 동안 CPU를 계속 사용합니다.
- 기록 파일을 여러 프로그램이 동시에 쓰는 경우는 고려하지 않았습니다.
